# Rockstar Match-3 Prototype

Mobile-first match-3 puzzle prototype with a live concert / music performance theme.

This project is only a **vertical slice prototype**, not the full commercial game.

## Tech target

- Phaser 3
- TypeScript
- Vite
- Mobile-first responsive layout
- Runs in browser first
- Later can be packaged as PWA / mobile app

## Core MVP

Build one playable level first.

Features required:

1. 8x8 match-3 board
2. Six music-themed tile types
3. Swap adjacent tiles
4. Detect matches of 3 or more
5. Clear matched tiles
6. Cascade / gravity
7. Refill empty spaces
8. Moves counter
9. Objective: collect 10 gold records
10. Crowd Energy meter
11. Win and lose screen
12. Simple stage header above the puzzle board
13. Basic power-up from 4-match
14. Mobile-friendly UI

## Theme

Every puzzle level represents a live concert.

The puzzle board is the concert energy.
Matches increase crowd excitement.
Power-ups trigger stage effects.
Winning feels like finishing a successful performance.

## Do NOT build yet

Do not add these in the first prototype:

- backend
- login
- payments
- shop
- ads
- complex economy
- world map
- thousands of levels
- online multiplayer

First goal:

**The player can swap tiles, make matches, collect records, build crowd energy, and win or lose one level.**
