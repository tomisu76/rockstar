# Antigravity Task Prompt

Build the first playable prototype only.

Create a Phaser 3 + TypeScript + Vite mobile-first match-3 game called Rockstar.

Use the files in this folder as the product brief.

## Implement

1. 8x8 match-3 board
2. six music-themed tile types
3. tile swapping
4. adjacent swap validation
5. match detection
6. clearing matched tiles
7. cascade / gravity
8. refill empty spaces
9. moves counter
10. objective panel: collect 10 gold records
11. crowd energy meter
12. win and lose overlay
13. simple stage header above the puzzle board
14. basic power-up created by 4-match
15. mobile-first responsive layout

## Use placeholder graphics first

Use simple colored shapes, emoji, SVG, or generated canvas icons.
Do not depend on final art assets.

## Do not implement

- backend
- login
- payment
- ads
- shop
- multiplayer
- complex map
- thousands of levels

## Main success criteria

The game must be playable in the browser.

A player can:

1. open the game
2. swap tiles
3. create matches
4. collect gold records
5. see crowd energy increase
6. run out of moves or win the level

Keep the code simple, readable, and easy to extend.
